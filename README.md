# Business Problem Excel Portfolio Project

This repository contains an Excel-based business problem exercise prepared as a portfolio project.

## Project Objective

The goal of this project is to solve a small business problem using Microsoft Excel and present the work in a structured, reviewable format.

## Files

- `business_problem_excel_exercise.xlsx` - the original Excel workbook

## Step-by-Step Process To Solve The Business Problem

### 1. Understand the problem

Open the workbook and read the instructions carefully. Identify:

- what the business wants to know
- what decision needs to be made
- what output is expected

At this stage, convert the general business problem into a simple question such as:

- Which product performs best?
- Which region has weak sales?
- Why did profit decrease?
- What should the business improve first?

### 2. Review all sheets in the workbook

Check each worksheet and understand what it contains:

- raw data
- assumptions
- lookup tables
- summary sections
- charts or reports

This helps you avoid missing important inputs before starting the analysis.

### 3. Inspect the data quality

Before doing calculations, verify that the data is usable:

- check for blank cells
- check for duplicate rows
- check whether dates are real dates
- check whether sales, cost, and profit are numeric values
- check for inconsistent naming such as `North`, `north`, or `NORTH`

If the data is not clean, the final result will be wrong.

### 4. Clean and prepare the data

Fix the problems found in the dataset:

- remove duplicates if needed
- standardize names and categories
- fix broken formatting
- convert text values into numbers
- make percentages, currency, and dates consistent

This step creates a reliable base for analysis.

### 5. Define the business questions clearly

Break the problem into smaller questions, for example:

- What happened?
- Where is the issue happening?
- Which category, product, or region is responsible?
- How large is the impact?
- What action should be recommended?

This keeps the analysis focused and avoids random calculations.

### 6. Choose the right Excel methods

Use formulas and tools based on the problem type.

Common formulas:

- `SUM` for totals
- `AVERAGE` for averages
- `COUNT` and `COUNTIF` for counts
- `SUMIF` and `SUMIFS` for conditional totals
- `IF` for business logic
- `VLOOKUP` or `XLOOKUP` for matching values
- percentage change formulas for trend comparison

Common tools:

- Sort and Filter
- PivotTables
- Charts
- Conditional Formatting

### 7. Build the calculations

Create the actual analysis in Excel:

- calculate totals
- compare categories
- measure trends over time
- calculate profit, margin, growth, or other required metrics
- create PivotTables if the data is large

Keep formulas clean and easy to audit.

### 8. Identify insights from the results

Once the numbers are ready, study the output:

- find top-performing and low-performing areas
- identify unusual spikes or declines
- compare periods, products, or locations
- connect the numbers back to the business question

This is where analysis becomes a business conclusion.

### 9. Write the business conclusion

Summarize the answer in simple language:

- what the data shows
- what the key problem is
- what action should be taken

A strong portfolio project does not stop at formulas. It explains the meaning of the results.

### 10. Improve presentation quality

Make the workbook easy to review:

- add clear sheet names
- label outputs properly
- highlight final answers
- format tables neatly
- add charts if they improve understanding

Presentation matters because employers and reviewers need to understand your work quickly.

### 11. Package the work as a portfolio project

A portfolio-ready Excel project should include:

- the original workbook
- a short README
- the business objective
- the analysis approach
- the final conclusion

This makes the project more professional and easier to share.
